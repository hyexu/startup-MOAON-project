음성 인터뷰 서비스 1단계 작업 정리

2026-11-25 · 담당: 서비스 핵심 동작(AI 음성 인터뷰) 기획·개발·배포

요구사항 정의, 설계 결정, 검증, 배포는 직접 했고, 코드 작성은 AI 코딩 도구(Claude Code)로 진행했습니다.

부모님이 휴대폰 링크 하나로 말로 답하면, AI가 답을 듣고 다음 질문을 이어 가며 기록하는 서비스를 하루 만에 설계, 구현, 배포했습니다.

배포된 서비스 부모님 화면 체험 (저장 안 함)
25커밋
~3,000서비스 코드 줄
87자동 테스트 (단위 83 + 브라우저 4)
0원시범 단계 고정비
≈201턴 시험 AI 크레딧 (≈6원, 추정)

1AI 인터뷰 방식 설계

  • 인터뷰 지침 작성(skills/life-story-interviewer/SKILL.md): 질문은 한 번에 하나, 답의 구체적인 단어를 이어받는 후속 질문, 깔때기 6단계(열기 → 장면 → 감각 → 인물·대사 → 감정 → 의미), 기억이 안 날 때 단서와 선택지, 민감한 이야기는 넘어갈 수 있게, 지어내지 않기
  • claude.ai 체험판을 먼저 만들어 대화 품질을 확인

2팀 시스템 분석과 방향 결정

  • 팀원 상품 사이트와 관리자 웹의 공개 코드를 분석해 데이터 구조, 상태 이름, 동의 항목, 녹음 링크 방식을 파악
  • 팀원 저장소에 접근할 수 없어, 팀 시스템과 나중에 합칠 수 있게 맞추되 독립적으로 작동하는 환경을 따로 만들기로 결정
  • 상태 이름, 동의 항목, 디자인 색을 팀원 시스템과 똑같이 맞춤

3설계와 범위 결정

  • 설계 문서 작성: 목표·비목표·실패 조건, 어르신 사용성 원칙(한 화면에 행동 하나, 큰 글씨, 음성 안내, 전화 지원), 개인정보 원칙(국외 이전 별도 동의, 실명을 AI에 보내지 않음)
  • 실시간 통화 방식 대신 차례대로 주고받는 방식 선택: 질문 품질 통제, 답별 원본 녹음 보관, 최저 비용
  • 12월 14일 발표에 맞춰 1단계(작동하는 핵심)와 2단계(원고 편집, 삭제 등)로 범위 분리, 구현 계획을 작업 12개로 나눔

4비용 구조 설계 (경제성)

  • 유료 AI API 대신 고려대 BAZE 게이트웨이 도입: 키 하나로 Claude, 음성 인식(Soniox), 음성 합성(Gemini). 월 무료 크레딧, 학습 미사용 정책 확인
  • 키 여러 개를 차례로 사용(팀원 키 공유 가능). 크레딧이 떨어지면 AI를 멈추고 미리 정한 질문으로 녹음을 계속 받는 안전장치
  • 모든 AI 호출의 사용량을 기록해 한 권당 원가를 숫자로 제시할 수 있게 함
  • Vercel·Supabase 무료 플랜으로 시범 단계 고정비 0원

5서비스 구현

  • 부모님 화면: 링크 → 동의 2단계 → 마이크 → 질문 듣기 → 말로 답하기 → 오늘은 여기까지. 카카오톡 안 브라우저 안내, 휴대폰 임시 저장으로 끊김 대비, 아이폰 화면 꺼짐 대응, 두 번 누르기 방지, 체험 모드
  • 한 턴 처리: 녹음 저장 → 글로 옮기기 → 다음 질문(Claude Sonnet 5.5) → 질문 읽어 주기. 이야기 카드 정리(Claude Haiku 5.5)는 뒤에서
  • 운영자 화면: 부모님 등록, 질문 묶음, 링크 발급·중지, 대화 기록(녹음 재생과 글), 이야기 카드, 크레딧과 AI 멈춤
  • 품질: 독립 코드 검토에서 나온 10건을 재현 테스트로 확인하고 수정. 가장 중요했던 것은 다른 부모님 녹음에 접근할 수 있던 경로 우회 차단

6배포와 실제 환경 검증

  • Supabase(DB, 비공개 녹음 저장소, 운영자 로그인)와 Vercel 설정·배포
  • 배포 후 문제를 직접 찾아 해결: DB 비밀번호 인증 오류, 빈 녹음 처리 오류
  • 빨리 진단하려고 설정 점검 주소(/api/health)와 실패 사유 표시 기능 추가
  • 실제 휴대폰으로 부모님 흐름 확인

·팀과 연결되는 지점

  • 팀원 관리자 웹과 상태 이름·동의 항목·디자인 색을 같게 맞춰 나중에 합치기 쉽습니다.
  • 팀원 BAZE 키를 추가하면 무료 크레딧이 두 배가 됩니다.
  • 주문·결제·문의는 팀원 사이트가, "인터뷰가 실제로 돌아가는 부분"은 이 서비스가 맡습니다.

·다음 할 일

  • 실제 말소리로 휴대폰 3종(안드로이드 크롬, 아이폰 사파리, 카카오톡) 재확인
  • 가족 시범 세션 → 결과를 가명으로 요약 (질문 품질, 지어낸 내용 여부)
  • 2단계: 전사·원고 편집, 원고 초안, 내려받기·삭제, 부모님 최종 승인, PDF
