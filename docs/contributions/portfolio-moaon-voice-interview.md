# 모아온 — AI가 부모님의 인생 이야기를 듣는 음성 인터뷰 서비스

> 고려대학교 창업 수업 프로젝트 · 2026년 11월 · 역할: 서비스 핵심 기능 기획·개발·배포 (AI 코딩 도구 활용)
> 서비스: https://startup-moaon-project.vercel.app · 체험: https://startup-moaon-project.vercel.app/r?demo=1

## 문제

- 자녀가 따로 사는 부모님을 만나는 횟수는 1년에 12번 정도입니다(한국복지패널 중위값). 그 짧은 시간에 어린 시절이나 첫 직장 이야기를 일부러 여쭤보기는 어렵습니다.
- 기존 방법은 각각 한계가 있습니다.
  - **자서전 대필:** 49만 원 이상으로 비쌉니다.
  - **질문지 책:** 부모님이 직접 써야 해서 끝까지 채우기 어렵습니다.
- 65세 이상의 67.2%는 디지털 기기 사용을 어려워합니다(2023 노인실태조사).

## 해결

부모님은 **링크를 누르고 말씀만 하시면** 됩니다.
- AI 인터뷰어가 질문을 소리와 큰 글씨로 건넵니다.
- 답을 들으면, 그 답의 구체적인 단어를 이어받아 다음 질문을 만듭니다.
- 녹음은 그대로 보관되고, 글로 옮겨져 이야기 카드로 정리됩니다. 이 카드가 나중에 회고록 원고의 재료가 됩니다.

## 내가 한 일

| 단계 | 내용 |
|---|---|
| 인터뷰 설계 | 질문 원칙과 깔때기 6단계(열기·장면·감각·인물·감정·의미), 기억이 안 날 때 단서 주기, 민감한 이야기 처리, 지어내지 않기 원칙을 AI 지침으로 작성 |
| 제품 결정 | 실시간 통화 방식 대신 차례대로 주고받는 방식을 선택 (질문 품질 통제, 답별 원본 보관, 최저 비용). 발표 일정에 맞춰 1·2단계로 범위 분리 |
| 비용 구조 | 고려대 BAZE 게이트웨이로 AI 비용을 학교 크레딧 안에서 해결. 크레딧이 바닥나도 서비스가 멈추지 않는 안전장치, 호출별 원가 기록 |
| 개발 | Next.js 웹앱 — 부모님 화면, 한 턴 처리 파이프라인, 운영자 화면, 개인정보 안내 |
| 품질 | 자동 테스트 83개와 브라우저 테스트 4개. 독립 코드 검토에서 나온 10건(보안 1건 포함)을 재현 테스트로 확인하고 수정 |
| 배포·운영 | Supabase와 Vercel로 고정비 0원 배포. 배포 후 장애(DB 인증, 빈 녹음)를 점검 도구를 만들어 진단하고 해결 |

## 기술 구성

```
부모님 휴대폰 (링크, 회원가입 없음)
   │ 녹음 업로드 (비공개 저장소에 바로 올림)
   ▼
Next.js 서버 (Vercel) ── 한 턴: 녹음 → 글로 옮기기 → 다음 질문 → 질문 읽어 주기
   │                          (Soniox)      (Claude Sonnet)  (Gemini TTS)
   │                     └─ 뒤에서: 이야기 카드 정리 (Claude Haiku)
   ▼
Supabase (Postgres, 비공개 Storage, 운영자 로그인)
```

- **사용 기술:** Next.js 16, TypeScript, Drizzle ORM, Supabase, Vercel, Anthropic Claude, BAZE API Gateway, ffmpeg, Vitest, Playwright
- **개발 방식:** 요구사항 정의 → 설계 문서 → 작업 12개 계획 → 테스트 먼저 작성 → 구현 → 독립 검토 → 수정. 코드는 AI 코딩 도구(Claude Code)로 작성하고, 결정과 검증은 직접 했습니다.

## 고민했던 점

1. **어르신이 막히지 않게 만들기**
   - 한 화면에 버튼 하나, 질문은 자동으로 소리 내어 읽기
   - 카카오톡 안에서 열면 다른 브라우저로 여는 방법 안내
   - 녹음은 5초마다 휴대폰에 저장해서, 창이 닫혀도 다시 열면 이어서 보냄
   - 버튼을 두 번 눌러도 한 번만 처리
2. **개인정보**
   - 링크 키는 서버에 해시로만 저장합니다.
   - AI에는 실명 대신 호칭("어머님")만 보냅니다.
   - 국외 이전 동의는 따로 받습니다.
   - 오류 기록에도 답변 내용이 남지 않게 했습니다.
3. **비용과 안정성**
   - 크레딧이 떨어지면 AI를 멈추고 미리 정한 질문으로 녹음을 계속 받습니다.
   - 글로 옮기기는 나중에 운영자가 한 번에 처리합니다.

## 결과

- 하루 만에 실제 휴대폰에서 작동하는 서비스를 배포했습니다.
- 시범 단계의 고정비는 0원이고, AI 원가는 1턴 시험 기준 약 20크레딧(약 6원, 추정)입니다.
- 코드 약 3,000줄, 테스트 약 1,100줄, 커밋 25개

## 배운 점

- 핵심을 먼저 검증하는 게 중요했습니다. 체험판으로 질문 품질부터 확인한 뒤 정식 구현에 들어갔습니다.
- 사용자가 "실수로 바로 '다 했어요'를 누르는" 것 같은 현실의 상황은 실제 기기에서 써 봐야 드러났습니다. 그래서 문제를 빨리 찾을 점검 도구를 미리 만들어 두는 게 효과적이었습니다.
- AI 코딩 도구를 쓰면 구현 속도가 크게 빨라집니다. 대신 범위, 우선순위, 개인정보, 사용자 경험의 판단은 사람이 정확히 내려야 했습니다.
